# Food Journey Modern

Modernisierte React/Vite-Version für kostenloses Hosting auf GitHub Pages.

## Lokal starten

```bash
npm install
npm run dev
```

## Für GitHub Pages

1. Neues GitHub-Repository anlegen.
2. Alle Dateien aus diesem Ordner hochladen.
3. Repository-Name idealerweise `food-journey-modern` lassen, damit die `base`-URL in `vite.config.js` direkt passt.
4. Unter **Settings > Pages** als Source **GitHub Actions** aktivieren.
5. Danach einfach auf `main` pushen.

Die Seite wird dann automatisch gebaut und kostenlos auf GitHub Pages veröffentlicht.
